Nuvem GitHub & Sync

Mesmo modelo do LifeHub: o site fica no repositório público do GitHub Pages e os dados do closet ficam num repositório privado, separado, acessado por um token fine-grained.

☁️ Conector GitHub API (Push / Pull / Auto-Sync)

🔒 Privacidade: aqui vão peças, fotos, joias, relógios, valores, onde estão guardados e os Looks do Dia (com fotos). Use um repositório PRIVADO só para os dados (ex.: usuario/closet-raquel-dados), separado do repositório público do site (GitHub Pages). Nunca sincronize no mesmo repositório público do Pages — qualquer pessoa poderia baixar, e o histórico de commits guarda tudo para sempre.
Pronto para configurar e testar.
Informe o repositório PRIVADO de dados e o token fine-grained para habilitar a nuvem.
Closet v5 • PWA, fotos no IndexedDB e sync protegida (modelo LifeHub v5.8)

🔑 Como configurar a nuvem com segurança

  1. Crie um repositório novo e PRIVADO só para os dados (ex.: closet-raquel-dados). Não use o repositório do site (GitHub Pages), que normalmente é público.
  2. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Em Repository access escolha Only select repositories e marque apenas o repositório de dados.
  4. Em Repository permissions → Contents selecione Read and write. Não marque mais nada. Defina uma data de expiração.
  5. Não use token Classic com escopo repo: ele abre acesso a todos os seus repositórios.
  6. Cole o token acima, clique em 💾 Salvar Config, depois em 🔌 Testar Conexão (ele avisa se o repositório for público ou publicar site) e por fim em ☁️ Enviar p/ Nuvem (Push).
  7. Em outro aparelho: configure igual e use 📥 Baixar da Nuvem antes de editar.

O token fica salvo só neste navegador (ou só nesta sessão, se você escolher). Se o celular for perdido, revogue o token no GitHub.

Sua coleção, protegida.

Exporte seus dados e imagens para recuperar o acervo quando necessário.

Backup completo

O arquivo JSON inclui tudo: peças e fotos, looks salvos, agenda, favoritos, Looks do Dia (com fotos), perfil de estilo e lista de desejos. Guarde uma cópia fora deste aparelho. Backups antigos (só peças) continuam podendo ser restaurados.

O acervo é salvo neste navegador e pode ser sincronizado com o GitHub quando a conexão estiver configurada. Mantenha backups JSON regulares.

Espaço & app no celular

Peças e fotos do Look do Dia ficam no banco do navegador (IndexedDB), que tem bem mais espaço. Looks, agenda e o texto do diário ficam no armazenamento leve (~5 MB). O backup e a nuvem levam tudo junto, fotos incluídas.
